## BÖLÜM B — VERİ ERİŞİM REÇETESİ (TEKRARLANABİLİR)

### B.1 — Bir Meadview boş lotunun absentee sahibine ÜCRETSİZ ulaşma (manuel, adım adım)

1. **Lotu seç** → örn. Lot 7 W Coral Tree Drive, Meadview. Plat/sokaktan APN'i öğren.
2. **Mohave Assessor search** ([assessor-search](https://www.mohave.gov/departments/assessor/assessor-search/)) → APN veya situs adresiyle sorgula.
3. Sonuç ekranında oku: **Owner Name**, **Mailing Address** (mail_address1/3), **Situs/Physical Address**, **Land Use Code** (boş arsa mı?), **Acreage**, **Assessed Value**.
4. **Absentee tespiti:** Mailing address ≠ situs address (sahip arsada oturmuyor, başka eyalette) → off-market hedef.
5. **Boş arsa tespiti:** land_use_code = vacant/unimproved + yapı yok.
6. Mektubu **mailing address**'e gönder. Maliyet: **$0** (sadece pul).

→ Rina tam olarak bunu yapıyor: assessor'dan absentee+vacant sahibi bul → mektupla "arsanı $X'e alırım" teklifi → $2.999'a sat.

### B.2 — Toplu çekme (bulk) — ÜCRETSİZ yol (önerilen başlangıç)

**Mohave PARCELS ArcGIS REST FeatureServer** (mcgis2.mohavecounty.us). Tek HTTP query ile binlerce parsel:
```
.../PARCELS/MapServer/0/query
  ?where=land_use_class LIKE '%VACANT%' AND mail_address3 NOT LIKE '%AZ%'
  &outFields=parcel_id,owner,mail_address1,mail_address3,address,acreage,land_use_code
  &f=json&resultRecordCount=2000&resultOffset=0
```
- `where` ile **vacant + absentee (mailing eyaleti AZ değil)** filtrele.
- `resultOffset` ile sayfalama → tüm county parsellerini ücretsiz çek.
- Maliyet: **$0**. Mohave County ~**250.000+ parsel** (Regrid kapsamı); vacant+absentee alt-kümesi muhtemelen **birkaç on bin**.

### B.3 — Toplu çekme — TİCARİ API (ölçek + temiz veri)

**ReportAll USA** ([reportallusa.com/products/api](https://reportallusa.com/products/api)) — 160.6M parsel, ABD'nin %99'u, Arizona/Mohave dahil. Owner + mailing address + acreage + land use döndürür.
- **Bulk Data Store fiyatı (doğrulandı):** county indirimi $2.500–4.999 → **%10**, $5.000+ → **%20**; eyalet seti "zaten derin indirimli". Tam county'yi tek seferde lisanslamak için. ([volume-discount-pricing](https://reportallusa.com/volume-discount-pricing))
- Per-query API fiyat tablosu sayfası bu ortamda **CSS error / yüklenemedi** — net $/sorgu **doğrulanamadı**, sales@reportallusa.com'dan teyit gerek.
- **Esri Feature Service** seçeneği de var (ArcGIS'e direkt bağlanır).

**Regrid** ([app.regrid.com/us/az/mohave](https://app.regrid.com/us/az/mohave)) — nationwide standart parsel şeması, owner+mailing+land use+acreage. County tile / API fiyatı sayfada yok → **parcels@regrid.com** ile konuşulur (enterprise). Mohave County parsel sayısı sayfada listelenmiyor ama kapsam mevcut.

**Pratik tahmin:** Mohave için **ücretsiz ArcGIS REST yeterli** (vacant+absentee birkaç on bin parsel, $0). 50-eyalet ölçeğine çıkınca county-county REST sürdürülemez → o zaman ReportAll bulk (county başına birkaç yüz $) veya Regrid lisansı.

## BÖLÜM C — ALIŞ vs SATIŞ SPREAD (MARJ)

| Kalem | Rakam | Kaynak / mantık |
|-------|-------|-----------------|
| **Satış (Rina retail)** | **$2.999** (1 ac Meadview) | Doğrulanmış canlı fiyat |
| Pazar retail bandı | $3.000–$9.000 | A.2 tablosu |
| **Alış — tax-deed/OTC** | **~$300–$1.500** | Mohave OTC parselleri tipik açılış/min bid birikmiş vergi + masraf; çöl 1-acre lotlar bu bantta |
| **Alış — absentee mektup** | **~$300–$900** | Land Academy/REtipster benchmark: çöl absentee sahibi piyasa değerinin %10–40'ına satar; comp'lardan ~$2.000 değerli lot → $300–$900 alış |
| Mektup maliyeti | ~$0.52–0.80/mektup | Lob/PropStream postcard |
| Skip-trace (gerekirse) | ~$0.06–0.12/kayıt | Assessor mailing varsa **gerekmez = $0** |

**Net spread (1 lot):** ~$300–$900 alış → $2.999 satış = **~$2.100–$2.700 brüt marj/lot** (mektup + tapu/closing düşülür). Owner-finance ile $500 down + aylık taksit → nakit akışı + faiz üstüne.

> Yani Rina'nın "sihri" yok: ücretsiz assessor verisi + mektup + tek-fiyat retail. Terralot bunu **otomatik + ölçekli** yapacak.

**Detay:** `ALL-STATES-LAND-RESEARCH.md` (50 eyalet tier'lı). Burada motor-kararı özeti:

| **Wyoming** | ~$1.000 | 35+ ac agri-muaf; income tax yok |
| **Nevada** | ~$1.230 | Esmeralda/Lincoln/Nye ucuz |

### Veri kazananı
- **Ücretsiz katman:** County ArcGIS REST + assessor (Mohave'de kanıtlandı). İlk eyaletler için $0.
- **Ölçek katmanı:** **ReportAll** (160M parsel, county bulk %10–20 indirim) + **Regrid** (standart şema, enterprise API). İkisi birlikte = 50-eyalet kapsama.

### Hukuk (US dışı alıcı / owner-finance)
- **FIRPTA:** Yabancı satıcı ABD gayrimenkulü satınca alıcı satış bedelinin **%15'ini stopaj** yapıp IRS'e öder (Ahmet/Terralot **satıcı** tarafında → satışta uygulanır; alış tarafında değil). Türk yatırımcıya net etki: çıkışta planlanmalı.
- **CFD (Contract for Deed) / Owner Finance:** Compass/LANDiO modeli — tapu son taksitte geçer, <$4K lotlarda CFD, üstünde title company. Eyalet bazlı tüketici koruması var (özellikle TX, MN'de CFD sıkı) — sözleşme eyalete göre.
- **Down/faiz çıpası:** $500 down, %7.9 faiz, 60 ay (pazar standardı) — Rina $500 down ile birebir aynı.

### Veri + mektup bütçesi (50-eyalet ölçek tahmini)
- **~$1.000 veri** (ReportAll/Regrid çoklu county bulk) + **~$800 mektup/1000 sahip** (Lob) → 1000 absentee sahibe ulaşım ~$1.800. %1–3 dönüş → 10–30 lead → birkaç deal.
